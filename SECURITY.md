# Security

Flux serves its control page to the whole local network and holds the key to
your Hue bridge. If you find a way to control Flux, read its settings or reach
the bridge without being meant to, please report it privately:

- **[Report a vulnerability](https://github.com/Oulsen/Flux/security/advisories/new)**
  (GitHub's private reporting), not in a public issue.
- Say which Flux version and Windows version, what someone can do with it, and
  how to reproduce it.

You get an answer in the report. A fix ships in a release; the report becomes
public after that, with credit if you want it.

Only the latest release gets fixes.
